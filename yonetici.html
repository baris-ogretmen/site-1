🤖 Robot Asistan

Bağlantı boşsa Biri site içi içerik rehberi olarak çalışır. Yapay zekâ için anahtarı sunucuda tutan bir API bağlantısı gerekir.

POST {message} isteğine {reply} JSON yanıtı veren HTTPS uç noktası.

Bu yönerge yöneticiye özel robot kaydında saklanır. Sunucu bu kaydı okuyacak şekilde bağlanmalıdır.

Eski robot kaydında tarayıcıdan okunabilen bir API anahtarı var. Google AI Studio’da anahtarı yenile; yeni anahtarı yalnızca sunucuda sakla.
